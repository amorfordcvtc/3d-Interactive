# 3d-Interactive
this is for sharing 3d interactive app models. often with the assistance of AI.

requires Python, panda3d, math

## Building a Bootable OS ISO

See the [os_builder](os_builder) directory for a script that assembles a minimal
Linux ISO running the `icoTest` icosahedron file manager on boot. Run
`./os_builder/build_iso.sh` to create `icosa_os.iso`.
